# Claude Adds

أداة سطح مكتب عربية لنظام Windows 11. من نافذة واحدة تبحث باسم أداة أو بالمهمة، فتعرف ما عندك، ووظيفة كل أداة، وهل عندك بديل يغطي الحاجة نفسها، وأين تستطيع تثبيتها.

تغطي ست بيئات: Claude، Claude Code، ChatGPT، Codex، Gemini، Antigravity.

## التشغيل

المتطلبات: Node.js 20 أو أحدث، وGit لإضافة الأدوات من رابط. بقية أدوات المنصات اختيارية، وما ليس مثبّتًا يظهر بحالته الفعلية.

```bash
npm install
```

```bash
npm start
```

## الحزم الجاهزة

من صفحة [الإصدارات](https://github.com/sufyanaser/Claude-Adds/releases):

| النظام | الملف | ملاحظات |
|---|---|---|
| Windows 11 | `Claude-Adds-<version>-setup.exe` | مُثبِّت. هذه النسخة تحدّث نفسها تلقائيًا. غير موقّع، فقد يظهر تحذير SmartScreen. |
| Windows 11 | `Claude-Adds-<version>-portable.exe` | محمول، يعمل دون تنصيب. يُشعرك بالتحديث ولا يحدّث نفسه. |
| macOS (Apple Silicon) | `Claude-Adds-<version>-mac-arm64.dmg` | موقّع محليًا فقط وغير موثّق من Apple. عند أول فتح: انقر بالزر الأيمن على التطبيق ثم «فتح». |
| macOS (Intel) | `Claude-Adds-<version>-mac-x64.dmg` | كالسابق. |

تنصيب نسخة macOS من الطرفية بأمر واحد. يختار الحزمة المناسبة للمعالج، ينسخ التطبيق إلى `/Applications`، ويزيل علامة الحجر عن التنزيل:

```bash
curl -fsSL https://raw.githubusercontent.com/sufyanaser/Claude-Adds/main/scripts/install-mac.sh | bash
```

## التحديث التلقائي

من «المنصات والمصادر» ثم «تحديث التطبيق»:

| القناة | ما تتبعه |
|---|---|
| مستقرة | الإصدارات الرسمية الموسومة فقط |
| تطويرية | بناء آلي يصدر مع كل دفع إلى فرع `develop` |

- يتحقق التطبيق بعد التشغيل بثوانٍ ثم كل ثلاث ساعات، وبزر «التحقق الآن».
- **النسخة المُنصَّبة على Windows** تنزّل المُثبِّت من إصدارات هذا المستودع فقط، تتحقق من حجمه وبصمة SHA-256 المعلنة، ثم تثبّته عند إغلاق التطبيق أو فورًا بزر «إعادة التشغيل والتحديث الآن».
- **النسخة المحمولة ونسخة macOS** تعرضان إشعارًا برابط الإصدار الجديد، ولا تحدّثان نفسيهما.
- يمكن إيقاف التنزيل التلقائي، والبناء الذي يحمل `-dev` في رقمه يبدأ على القناة التطويرية.

## النسخة الاحتياطية

من «المنصات والمصادر» ثم «نسخة احتياطية»: اختر مسار التصدير مرة واحدة، ثم «إنشاء نسخة احتياطية الآن». ينشأ مجلد مؤرَّخ `Claude-Adds-backup-<التاريخ>` يحتوي:

- `manifest.json`: جرد أدواتك في كل بيئة مع حالتها ومصدرها وأوامرها.
- `skills/`: نسخ من مجلدات المهارات التي تملكها، مرتبة حسب مصدرها.
- `README.txt`: خطوات الاستعادة.

لا تتضمن النسخة مفاتيح ولا رموزًا، وتُستثنى ملفات مثل `.env` والمفاتيح الخاصة والروابط الرمزية. إضافات المنصات وموصلاتها تُعاد بتثبيتها من مصدرها، ومصادقة الموصلات تُعاد يدويًا.

طريقة إصدار النسخ في [RELEASING.md](RELEASING.md)، وسجل التغييرات في [CHANGELOG.md](CHANGELOG.md).

نسخة Windows مختبرة عمليًا على Windows 11. نسخة macOS تُبنى آليًا على خادم macOS ويُتحقق هناك من أنها تقلع فقط، ولم تُختبر واجهتها على جهاز Mac.

## الشاشات

- **أدواتي** (شاشة البداية): كل ما هو موجود فعلًا على الجهاز أو في الحساب. عند البحث تظهر أدواتك أولًا ثم نتائج الكتالوج.
- **الكتالوج**: ما يمكن إضافته وليس عندك.
- **المنصات والمصادر**: ما ثبت لكل منصة (الجرد، التثبيت، المزامنة، تسجيل الدخول)، وحالة كل مصدر بيانات ووقت آخر تحقق.
- **شريط الوصول السريع** أعلى النافذة: الكل، Claude، Claude Code، ChatGPT، Codex، Gemini، Antigravity.

## معنى الحالات

كل حالة تسمّي ما يثبته الدليل فقط:

| الحالة | الدليل |
|---|---|
| مكتشفة | وُجد ملفها أو مدخلها في الإعداد، ولا دليل على تحميلها |
| مثبّتة | مسجّلة في سجل التثبيت، وتفعيلها غير مؤكد |
| مفعّلة، معطّلة | المنصة نفسها تقرّر ذلك عبر أمر الجرد |
| متصل مؤكد | نجح فحص اتصال حي |
| يتطلب مصادقة | المنصة تطلب تسجيل دخول لهذا الموصل |
| مُعدّ، غير مُعدّ | موجود في الإعداد دون فحص اتصال، أو عنصر نائب بلا عنوان |
| تعذّر التحقق | لا دليل كافٍ |

الأداة الواحدة تُعرض بحالتها في كل بيئة ونطاق على حدة، والأدوات المتشابهة الأسماء من مصادر مختلفة تبقى سجلات مستقلة.

## من أين تأتي البيانات

| البيئة | الجرد | التثبيت المباشر |
|---|---|---|
| Claude Code | `claude plugin list --json`، `claude mcp list`، ملفات `SKILL.md` | الإضافات بـ`claude plugin install`، والمهارات بنسخها إلى `~/.claude/skills` |
| Claude (الحساب) | مجلدات مزامنة الحساب وموصلات claude.ai كما يسردها Claude CLI | يتطلب إكمالًا من إعدادات Claude في المتصفح |
| Codex | `codex mcp list --json`، `codex plugin list`، `~/.agents/skills` | المهارات بنسخها إلى `~/.agents/skills` |
| Gemini | `gemini mcp list`، `gemini skills list` | المهارات بنسخها إلى `~/.gemini/skills` |
| Antigravity | `agy mcp list`، `agy plugin list --json`، `~/.gemini/config/skills` | المهارات بنسخها إلى `~/.gemini/config/skills` |
| ChatGPT | لا يوجد مصدر محلي موثّق، فتظهر «تعذّر التحقق» | يتطلب إكمالًا من chatgpt.com |

مسارات المهارات مأخوذة من الوثائق الرسمية لكل منصة. عند تعذّر تحديث مصدر تُعرض آخر نتيجة ناجحة مع تاريخها وسبب التعذّر، ولا يُعرض التثبيت المباشر من بيانات قديمة.

## إضافة أداة

من زر «إضافة أداة من رابط Git» أو من تفاصيل أداة في الكتالوج:

1. يُنزَّل المستودع إلى مجلد مؤقت وتُقرأ ملفاته كبيانات. لا يُشغَّل شيء منه، وتُتجاهل الروابط الرمزية.
2. تُعرض العناصر المكتشفة ونوعها (إضافة، مهارة، امتداد Gemini، خادم MCP) ودليل توافق كل عنصر مع كل وجهة، مع النطاق والإجراء والأمر أو المسار.
3. لا يتغير شيء قبل اختيار الوجهات والتأكيد.
4. تُنفَّذ كل وجهة وحدها وتُعرض نتيجتها، مع تحقق بجرد جديد. الوجهة المتعثرة تُعاد محاولتها وحدها.

يُقبل رابط https فقط ودون بيانات اعتماد في الرابط. لا يُمرَّر `-y` إلى Claude CLI، ولا يُستبدل مجلد موجود. خوادم MCP وامتدادات Gemini تظهر «يتطلب إكمالًا» مع الأمر الرسمي لأنها تحتاج مفاتيح أو موافقة في الطرفية.

تسجيل دخول المنصة، ومصادقة كل موصل، والتثبيت المحلي ثلاث خطوات منفصلة. ما يتطلب تسجيل دخول يُفتح في مساره الرسمي في متصفح الجهاز أو في طرفية الأداة نفسها، والتطبيق لا يرى كلمات المرور ولا الرموز.

## الخصوصية

لا تُقرأ حقول `env` و`headers` و`oauth` من إعدادات MCP، وتُنقّى عناوين الخوادم وأسطر الأوامر من أي قيمة تشبه مفتاحًا قبل عرضها أو حفظها. يُخزَّن محليًا: نسخة الكتالوج العامة، آخر نتيجة ناجحة لكل مصدر بعد التنقية، ومسار المشروع المحدد.

## متغيرات للاختبار

| المتغير | الأثر |
|---|---|
| `CLAUDE_CONFIG_DIR` | مجلد إعداد Claude Code بديل (متغير موثّق في Claude Code) |
| `CLAUDE_ADDS_HOME` | مجلد منزل بديل لمسارات المهارات، ويتخطى أدوات المنصات الأخرى |
| `CLAUDE_ADDS_CLAUDE_BIN` | مسار بديل لـ Claude CLI. مسار غير موجود يحاكي غيابه |
| `CLAUDE_ADDS_CATALOG_URL` | عنوان بديل للكتالوج |
| `CLAUDE_ADDS_USER_DATA` | مجلد بيانات مؤقت بدل مجلد التطبيق |
| `CLAUDE_ADDS_ALLOW_LOCAL_GIT` | يسمح بمسار مستودع محلي بدل رابط https |
| `CLAUDE_ADDS_EXE` | تشغيل الاختبار العملي على ملف تنفيذي محزوم |
| `CLAUDE_ADDS_E2E_ONLY` | تشغيل مجموعات محددة: `real`، `sim`، `isolated` |

الاختبار العملي يوسم كل فحص: `REAL` قراءة فقط على الجهاز الحقيقي، `REAL-ISOLATED` Claude CLI الحقيقي يكتب في مجلد إعداد مؤقت، `SIM` بديل عن CLI ومجلد منزل مؤقت.

## حدود الإصدار الحالي

- الوصف العربي مكتوب يدويًا لإضافات Anthropic الثماني عشرة المستضافة في الكتالوج. الباقي يحمل صياغة عامة مع النص الأصلي.
- البدائل تُقترح عند دليل واضح فقط: الخدمة نفسها، الاسم نفسه من مصدر آخر، أو الفئة نفسها مع كلمات وظيفية مشتركة.
- إضافات Codex وAntigravity وامتدادات Gemini وخوادم MCP لا تُثبَّت مباشرة، ويُعرض أمرها الرسمي.
- لا يوجد تعطيل أو إزالة من داخل التطبيق.
