# Claude Adds

أداة سطح مكتب عربية لنظام Windows 11 تجمع إضافات Claude ومهاراته وموصلاته في واجهة واحدة: ما المتاح، ما المثبّت والمفعّل، متى تُستخدم كل أداة، وكيف تبدأ بها.

## التشغيل

المتطلبات: Node.js 20 أو أحدث. Claude CLI اختياري، لكن بدونه تُعرض البيانات المتاحة من الملفات فقط.

```bash
npm install
```

```bash
npm start
```

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm start` | بناء ثم تشغيل التطبيق |
| `npm run typecheck` | فحص الأنواع |
| `npm run lint` | فحص ESLint |
| `npm test` | اختبارات الوحدات |
| `npm run test:e2e` | اختبار عملي داخل نافذة التطبيق الحقيقية. لا تكتب على لوحة المفاتيح أثناء تشغيله، فالنافذة تظهر على سطح المكتب. |
| `npm run icon` | إعادة توليد `build/icon.png` من `build/icon.svg` |
| `npm run package` | حزمة Windows محمولة في `release/` |

## من أين تأتي البيانات

| المعلومة | المصدر | عند تعذّره |
|---|---|---|
| حساب Claude المرتبط | `claude auth status --json` | يظهر «متعذّر» مع زر تسجيل الدخول |
| الإضافات المثبّتة وحالة التفعيل والنطاق | `claude plugin list --json` | تُقرأ `installed_plugins.json` و`enabledPlugins` من `settings.json`، وما لا يمكن تأكيده يظهر «تعذّر التحقق» |
| حالة اتصال الموصلات | `claude mcp list` (فحص اتصال حي) | تُعرض الموصلات الموجودة في `.mcp.json` و`~/.claude.json` بحالة «مُعدّ» دون ادعاء اتصال |
| المهارات | ملفات `SKILL.md` في مجلدات الإضافات و`~/.claude/skills` ومجلد المشروع المحدد | |
| كتالوج Anthropic | `marketplace.json` في [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) | تبقى آخر نسخة ناجحة ظاهرة مع تاريخها |

كل حالة معروضة تحمل مصدرها ووقت آخر تحقق في لوحة التفاصيل.

## ما يغيّره التطبيق وما لا يغيّره

- القراءة فقط هي الأصل. لا يكتب التطبيق في ملفات إعداد Claude مباشرة.
- **التثبيت المباشر** ينفّذ `claude plugin install <name>@knowledge-work-plugins --scope user` عبر Claude CLI بعد نافذة تأكيد تعرض الأمر ومصدر الملفات، مع تحذير للإضافات التي يستضيفها طرف خارجي. لا يُمرَّر `-y`، فالإضافة التي تتطلب تأكيد أمر في الطرفية يرفضها CLI ويظهر السبب.
- **تسجيل الدخول** يفتح طرفية تشغّل `claude auth login`. التطبيق لا يرى كلمة المرور ولا الرموز.
- لا تُقرأ حقول `env` و`headers` و`oauth` من إعدادات MCP، وتُنقّى عناوين الخوادم وأسطر الأوامر من أي قيمة تشبه مفتاحًا قبل عرضها. لا يُخزَّن سوى نسخة الكتالوج العامة ومسار المشروع المحدد.

## المزامنة

تُحدَّث البيانات عند كل تشغيل، ثم تلقائيًا حسب الفترة المختارة في «نظرة عامة» (الافتراضي كل 15 دقيقة، ويمكن إيقافها). كل تحديث يفحص اتصال الموصلات كلها ويستغرق نحو نصف دقيقة.

## متغيرات للاختبار

| المتغير | الأثر |
|---|---|
| `CLAUDE_ADDS_CLAUDE_BIN` | مسار بديل لـ Claude CLI. مسار غير موجود يحاكي غياب CLI. |
| `CLAUDE_ADDS_CATALOG_URL` | عنوان بديل للكتالوج. عنوان لا يستجيب يحاكي فشل التحميل. |
| `CLAUDE_ADDS_USER_DATA` | مجلد بيانات مؤقت بدل مجلد التطبيق الحقيقي. |
| `CLAUDE_ADDS_EXE` | تشغيل الاختبار العملي على ملف تنفيذي محزوم بدل نسخة التطوير. |

## حدود الإصدار الحالي

- الوصف العربي مكتوب يدويًا لإضافات Anthropic الثماني عشرة المستضافة في الكتالوج. بقية الإضافات والمهارات والموصلات تحمل صياغة عربية عامة حسب الفئة مع النص الأصلي من المصدر.
- مهارات وموصلات الإضافات غير المثبّتة تظهر فقط للإضافات المستضافة في مستودع الكتالوج. إضافات الأطراف الخارجية لا تُعرف مكوّناتها قبل تثبيتها.
- لا يوجد تعطيل أو إزالة للإضافات من داخل التطبيق.
